# Desarrollo de Atlas Santiago

- Usa el checkout existente: cada tarea de nube ya está aislada. No crees worktrees salvo petición explícita.
- Conserva el diseño y los cálculos cuando la mejora sea puntual. Trabaja de forma incremental.
- No publiques datos financieros personales, respaldos o documentos de usuarios dentro de código, tests o assets.
- No inventes precios, proyectos, stock, ocupación, tasas o permisos de renta corta. DEMO solo con activación expresa y etiquetado separado.
- Toda integración debe declarar fuente, fecha, licencia y estado real. Un fallo conserva evidencia anterior o muestra sin datos.
- `npm ci`, `npm test`, `npm run build`. Para cambios de comportamiento, ejecuta pruebas funcionales relevantes con Chromium.
- No eludas TLS, firmas o checksums. No contrates servicios de pago ni envíes mensajes sin instrucción explícita.
- No alteres supuestos para mejorar artificialmente rentabilidad. Declara qué impuestos o costos no están determinados.
